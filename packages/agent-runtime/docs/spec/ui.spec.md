# UI Contract Spec: agent-runtime callback pages

## Surface

The only served UI is the static HTML response generated by startOAuthCallbackListener. The package exports no React components, component slots, theme API, CSS custom properties or interactive application shell. Bundled skill examples are content assets, not supported component entry points.

| Callback outcome | HTTP response | Visible content |
|---|---|---|
| Matching state with code | 200 HTML | Title Authorized; heading Authorized!; instruction to close the tab and return to the host application |
| Provider error, missing code/state or mismatch | 400 HTML | Title/heading Sign-in failed; escaped reason; instruction to retry sign-in from the host application |
| Other path | 404 plain text | Not found. |
| Already consumed / unavailable URL | 410 plain text | Listener already consumed. |

Rendering success confirms the callback was accepted; it does not await onCallback completing token exchange. Host authorization state must follow the callback operation's result, not the browser page's title. Stale/malformed callbacks receive an error page while the listener stays available for the expected callback. Timeout invokes onCallback with an error and closes the listener; it does not push a new page to an existing browser tab.

## Presentation and accessibility

Both HTML pages use `lang="en"`, UTF-8 metadata, a document title, one h1 and paragraph text. Provider error text escapes ampersands, angle brackets and both quote characters. There are no forms, keyboard handlers, focus management or live-region announcements. No localization or audited accessibility conformance is promised.

Current inline styles use 14px system-ui, 40px padding, 480px maximum width, centered text, foreground #222, secondary text #666 and failure text #c00. Consumers cannot configure these values through listener inputs. Failure has a text heading and reason as well as red color.

Evidence: [page renderer](../../src/providers/oauth-callback-server.ts), [callback tests](../../src/providers/__tests__/oauth-callback-server.test.ts). No browser or accessibility checks were run for this specification.
