# UI contract: @jini-ai/sidecar

The package is headless process supervision, IPC and registry/discovery support. It includes no tray, window, connection-status widget or stylesheet. Hosts render lifecycle/crash/restart state and supply shutdown/recovery decisions. JSON registry pointers are discovery metadata and must not be shown as verified authorization.

Public data and wiring: [API](api.spec.md). Outcomes: [errors](errors.spec.md). Lifecycle: [state](state.spec.md). Runtime behavior: [behavior](behavior.spec.md). No UI/runtime checks were executed.
