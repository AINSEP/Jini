# Skill: Theming

A theme is installed by someone else and filled with their content. So the
question this skill answers is **what does it contain**, not how any one page
looks — that is `<AI_DEV_SHOP_ROOT>/skills/ui-ux-design/SKILL.md`.

## How To Use

Read `references/inventory.md`. It is the checklist:

1. **Pages** — the essential eight, then the premium differentiators.
2. **Components** — the baseline set, then what is missing for premium.
3. **Patterns** — preset compositions, including page skeletons so a fresh install shows a real page instead of a blank one.
4. **The things people forget** — dark mode, empty states, long-form prose styling, mobile nav, the nine interaction states, reduced motion and focus rings, OG images, regions, RSS and favicons.

Work top-down. Pages define which components are required; components define which
patterns are possible; the last list is what separates a $0 theme from a paid one
and is where cheap themes visibly fall apart.

Mark what already exists before adding anything. A theme that exercises machinery
the host already has is worth more than one that reimplements it.
