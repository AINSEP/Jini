# Premium UI

Premium web and product UI guidance: raising perceived quality without sacrificing
clarity, conversion, performance, accessibility, or maintainability.

This file routes premium-design methods. It does not define another universal
workflow, completion checklist, or implementation contract; use `ui-loop.md` for
completion review. Its final output section only names source-specific decisions to
capture when these methods are used.

Load for websites, landing pages, SaaS screens, hero sections, service pages,
ecommerce pages, portfolios, dashboards, and UI copy where the ask is a premium,
expensive, luxury, high-converting, agency-grade, high-trust, or visually elevated
result.

## Choose The Design-School Notes

Never gate these notes on the user naming their sources. Select them from the actual
surface and scope:

An earlier version gated them on the user naming a source, a condition that rarely
fired; premium work then used this summary alone and became templated. The current
router gates on surface breadth instead. Keep the ambiguous-case default at “load
all three” so the same failure does not return under a different trigger.

- **Broad, open-ended, hybrid marketing/product, ecommerce, or high-stakes premium
  work:** load all three.
- **Clearly narrow marketing/first-impression work:** load Sam Crawford and
  Self-Made Web Designer.
- **Clearly narrow product UI, dashboard, or admin work:** load Self-Made Web
  Designer and Kole Jain.

When scope is ambiguous or crosses categories, load all three. Together they are
about 19KB (~5k tokens); the specific methods live in the notes, not this router.

| File | What it gives you |
|---|---|
| `sam-crawford-premium-websites.md` | Premium-website psychology and constraints — halo effect, cognitive fluency, peak-end moments, bespoke/real assets, commercial filtering, client ownership, and post-launch care. |
| `self-made-web-designer-core-skills.md` | The repeatable fundamentals — typography, layout, spacing, color, code literacy, conversion thinking — plus fast upgrades to an existing site: font pairing, a focal visual idea, visual rhyming, depth, opacity hierarchy, and forcing divergent variants instead of shipping the first workable one |
| `kole-jain-uiux-concepts.md` | Product-UI treatments — signifiers and affordances, contextual grids, typography ranges, color semantics, dark mode, shadows, icons/buttons, micro-interactions, and text-over-image overlays |

They are design schools, not absolute rules. When they conflict, state the
tradeoff, pick the advice that best fits the product, audience, and business goal,
and avoid blending incompatible aesthetics without a clear reason.

## Reference-Specific Output

When this router is activated, record the applicable premium decisions:

- first-impression target
- visual hierarchy and layout direction
- asset and imagery plan
- copy and CTA approach
- interaction and animation restraint
- risks or tradeoffs around performance, accessibility, conversion, and maintainability
