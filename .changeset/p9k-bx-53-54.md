`JsonRoutePorts.onReturnedError` (opt-in): a returned parse or handler failure reaches the host's writer with the core default status and the failing phase, so a host with a flat wire envelope answers returned failures and thrown refusals in the same shape. Without the port, returned failures keep the core `{ error }` envelope and never reach `onError` (base pins unchanged).
